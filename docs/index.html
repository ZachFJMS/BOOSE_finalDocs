Table of Contents

Namespace BOOSEapp

Classes

AppArray

Represents an array declaration command that creates and manages integer or real (double) arrays within the stored program.

AppBOOSEException

Handles the exceptions that occur within the BOOSE application. Provides error messages for components and outputs them to the canvas.

AppBoolean

Represents a boolean evaluation command that assigns true or false values to variables based on evaluated expressions.

AppCanvas

Provides drawing functionality for the BOOSE application, implementing the BOOSE.ICanvas interface. Handles drawing shapes, moving the cursor, setting colors, and rendering text on a bitmap surface.

AppCircle

Represents a command that draws a filled circle on the application canvas using a specified radius.

AppCommandFactory

Provides a factory for creating BOOSE command objects based on command names. Responsible for instantiating the correct command class corresponding to a given keyword.

AppDrawto

Represents a command that draws a line from the current cursor position to a specified point on the application canvas.

AppElse

Represents an ELSE command that executes when the associated IF condition evaluates to false.

AppEnd

Represents an END command that closes a compound block such as IF, WHILE, or FOR. It links the end of the block to its corresponding start command and controls loop flow.

AppEvaluation

Base class for evaluation commands that assign values to variables by evaluating expressions at runtime.

AppFor

Represents a FOR loop command that repeatedly executes a block of code while incrementing or decrementing a loop variable.

AppIf

Represents an IF conditional command that executes a block of commands when a condition evaluates to true.

AppInt

Represents a command that evaluates and assigns integer values to variables at runtime.

AppMoveto

Represents a command that moves the drawing cursor to a specified position on the application canvas.

AppParser

Responsible for parsing user input into BOOSE commands. Interacts with the command factory to create commands and the stored program to execute them.

AppPeek

Represents a command that retrieves a value from an array at a specified index and assigns it to a target variable (PEEK operation).

AppPen

Represents a command that sets the pen color on the application canvas using RGB values.

AppPoke

Represents a command that assigns a value into an array at a specified index (POKE operation).

AppReal

Represents a command that evaluates and assigns real (double) values to variables at runtime.

AppRect

Represents a command that draws a rectangle on the application canvas using specified width and height.

AppStoredProgram

Represents the main stored program responsible for managing commands, variables, program execution flow, and expression evaluation.

AppTri

Represents a command that draws a triangle on the application canvas using specified base length and height.

AppWhile

Represents a WHILE loop command that repeatedly executes a block of commands while a condition evaluates to true.

AppWrite

Represents a command that writes a specified text string to the application canvas.

Interfaces

IAppStoredProgram

Interface defining the core behaviour of the AppStoredProgram. Manages commands, variables, execution flow, and expression evaluation.
